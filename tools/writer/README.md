# 写作台

在自己电脑上写博客的小工具。像普通编辑器一样打字，后台自动存成 `src/content/blog/` 下的 Markdown；截图直接粘贴，自动压缩成 WebP 存进仓库。网站上没有任何编辑入口，它只在本机 `127.0.0.1` 上运行。

## 打开

```bash
pnpm install   # 第一次，或者依赖有变化时
pnpm write     # 打开 http://127.0.0.1:4400/
```

启动时会先 `git pull`，把另一台电脑上同步过来的内容拉下来。端口可以用 `WRITER_PORT=4500 pnpm write` 换掉。

## 怎么用

| 想做的事 | 操作 |
| --- | --- |
| 新建 | 左上角「新建」，选学习日志、长文或空白。模板只放几个提问，灰字提示不会写进文章 |
| 按项目整理 | 左侧按项目分组，组名右边的加号直接在这个项目里新建；文章的「项目」属性可以改到别的项目，输入新名字就是新项目。项目存在 frontmatter 的 `project` 字段 |
| 同步状态 | 左下角说明两台电脑是否一致，有改动时点「同步」 |
| 标题、列表、引用、代码块 | 行首输入 `/` 选；也可以照 Markdown 习惯输入 `## `、`- `、`> `、```` ``` ```` |
| 加粗、链接 | 选中文字，浮出的格式栏里点 |
| 贴图 | 截图后 Ctrl+V，或把图片拖进来；点一下图片可以写图片说明 |
| 画图、流程图 | 行首输入 `/画图` 打开手绘画板，画完点「放进文章」存成 SVG（在图片目录里，和截图一样随文章同步）。点一下画好的图，浮出的「接着画」可以打开继续改 |
| 保存 | 自动保存，Ctrl+S 立即保存 |
| 换电脑 | 左下角「同步」：提交并推送草稿，同时拉取另一台的改动 |
| 发布 | 右上角「发布」：检查标题和摘要，删掉没写的提问，然后提交并推送，网站自动构建上线 |

草稿也会推到 GitHub（两台电脑靠它同步）。仓库是公开的，草稿在仓库里看得到，但网站构建会过滤 `draft: true`，不会出现在网站上。

## 图片放在哪

`public/images/posts/<文章网址>/<内容哈希>.webp`，文章里引用 `/images/posts/...`。图片最长边压到 1600px、质量 80，动图保留动画。发布和同步时会删掉正文里已经不用的图片。

存储写在 `lib/images.mjs` 的 `createRepoImageStore` 里。以后图片多了要搬到 Cloudflare R2：实现同样接口的 R2 存储，再在网站构建时把 `/images/posts/` 前缀换成 R2 域名，已写的文章不用改。

## 代码结构

```
tools/writer/
├─ server.mjs        本地服务：接口 + 用 Vite 提供编辑器页面
├─ lib/posts.mjs     读写 Markdown 和 frontmatter
├─ lib/images.mjs    图片压缩和存储层
├─ lib/git.mjs       拉取、提交、推送（只碰文章和图片目录）
├─ lib/templates.mjs 模板和提问
└─ app/              编辑器界面（Tiptap）
```

文章字段直接用网站的 `src/content/schema.ts` 校验，写作台和构建的要求始终一致。
